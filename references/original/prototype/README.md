# Invento interactive UI prototype

Open `index.html` in a modern browser. No dependencies or backend required. On desktop, use the phone preview. On Android, it fills the screen.

Test: Add product → Scan → Product detected → Push to Talk → Review → Retry or Edit → Save → Scan another. The demo scan code is simulated. Browser speech recognition may be unavailable; use the demo voice phrase. You can also enter details manually.

Try Stock in, Stock out, Count, Alerts and History. Changes persist in browser localStorage. Use **Simulate offline** on desktop to check read-only behavior; refresh does not reset data. This is a UX demonstration, not a connected Expo app.
