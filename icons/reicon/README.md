# Icon provenance

The prototype's `assets/app.js` contains locally authored inline SVG paths on a consistent 24×24 grid. They are provisional, not official Reicon assets. Icons are centered in shared containers and decorative SVGs are hidden from assistive technology; actionable controls supply text or accessible labels.

Replace with licensed Reicon exports after the supplied Figma source is accessible and the actual icon set/usage rights are verified. Preserve viewBox alignment, stroke consistency and 48px primary interaction targets.
